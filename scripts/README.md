# Script interfaces

The command guides refer to small R/Python wrappers such as `edger_rnaseq.R`, `edger_atac.R`, and `integrate_rna_atac.R`. They are intentionally not implemented in this documentation-first pass because the user requested commands rather than executable analysis code. Referenced implementations are preserved under `Source/backup_scripts`.

When the original backup scripts become available, add them here with a provenance note and tests for their input/output contracts.
